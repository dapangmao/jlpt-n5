日语动词变形学习顺序

词汇表动词变形
ます形て形ない形、た形可能、意志、条件被动、使役、敬语变形附：核心助词备注

1. ます形 — 日常礼貌对话够用

变形规则

  • 五段动词：词尾う段 → い段 + ます（書く → 書きます）
  • 一段动词：去る + ます（食べる → 食べます）
  • 不规则：する → します／来る → 来ます（きます）

四个时态

形态 例子
现在/将来 行きます
否定 行きません
过去 行きました
过去否定 行きませんでした

衍生用法：〜ましょう（一起…吧）、〜ませんか（委婉邀请）

2. て形 — 最高频，必须背熟音便规则

五段动词音便

词尾 变化 例子
く → いて 書く → 書いて（例外：行く → 行って）
ぐ → いで 泳ぐ → 泳いで
う・つ・る → って 買う → 買って、待つ → 待って、帰る → 帰って
ぬ・ぶ・む → んで 死ぬ → 死んで、遊ぶ → 遊んで、読む → 読んで
す → して 話す → 話して

核心用法（按优先级）

  1. 〜てください — 请求（ちょっと待ってください）
  2. 〜ている — 进行/状态（雨が降っている、東京に住んでいる）
  3. て连接动作 — 朝起きて、顔を洗って、会社に行った
  4. 〜てから — …之后（手を洗ってから食べる）
  5. 〜てもいい — 许可（写真を撮ってもいいですか）
  6. 〜てはいけない — 禁止
  7. 〜てみる — 试着…
  8. 〜てしまう — 完了/遗憾（口语：〜ちゃった）
  9. 〜ておく — 提前做好（口语：〜とく）
  10. 〜てあげる／てくれる／てもらう — 授受关系

3. ない形、た形 — 补全时态

ない形（否定）

  • 五段：词尾う段 → あ段 + ない（書く → 書かない）
  • 一段：去る + ない（食べる → 食べない）
  • 不规则：する → しない／来る → 来ない（こない）
  • 过去否定：〜なかった（書かなかった）

た形（过去）

  • 规则与て形完全相同：て → た、で → だ
  • 書いて → 書いた、読んで → 読んだ、食べて → 食べた

4. 可能、意志、条件 — 表达力上台阶

可能形（能…）

  • 五段：う段 → え段 + る（書く → 書ける）
  • 一段：去る + られる（食べる → 食べられる）
  • 不规则：する → できる／来る → 来られる

意志形（…吧）

  • 五段：う段 → お段 + う（書く → 書こう）
  • 一段：去る + よう（食べる → 食べよう）
  • 不规则：する → しよう／来る → 来よう

条件形（如果…）

  • 五段：う段 → え段 + ば（書く → 書けば）
  • 一段：去る + れば（食べる → 食べれば）
  • 例：飲めば分かる — 喝了就知道

5. 被动、使役、敬语变形 — 最后攻克

被动形（被…）

  • 五段：あ段 + れる（書く → 書かれる）
  • 一段：去る + られる（食べる → 食べられる）
  • 不规则：する → される／来る → 来られる

使役形（让…）

  • 五段：あ段 + せる（書く → 書かせる）
  • 一段：去る + させる（食べる → 食べさせる）
  • 例：子供に牛乳を飲ませる — 让孩子喝牛奶

敬语变形

  • 尊敬语（抬高对方）：食べる → 召し上がる
  • 谦让语（放低自己）：食べる → いただく
  • 通用句型：お + ます形词干 + になる（尊敬）／お + ます形词干 + する（谦让）

附：核心助词

助词是日语句子的骨架，标记每个词的语法角色，需与动词变形同步学习。

助词 功能 例子
は (wa) 主题 私は学生だ — 我是学生
が (ga) 主语/强调 雨が降る — 下雨
を (o) 宾语 本を読む — 读书
に (ni) 方向/时间/对象 東京に行く — 去东京
で (de) 地点/手段 電車で行く — 坐电车去
の (no) 所属 私の本 — 我的书
と (to) 和/引用 友達と話す — 和朋友说话
へ (e) 方向 学校へ行く — 去学校（与に近似）
から (kara) 起点/原因 9時から始まる — 9点开始
まで (made) 终点 駅まで歩く — 走到车站
も (mo) 也 私も行く — 我也去
か (ka) 疑问 行きますか — 去吗？

易混点

  • は vs が：は标记已知话题，が标记新信息或强调主语。初学先记句型，语感慢慢养
  • に vs で：に是到达点/存在地点（東京にいる），で是动作发生地（東京で働く）
  • に vs へ：都表方向，へ只表方向，に还兼表到达点、时间、对象，日常可互换

备注

  • て形是关键节点：音便规则背熟后，た形零成本掌握
  • 口语缩约形（ちゃった、とく、てる）出现率极高，听力必备
  • 结尾是る的动词不一定是一段：帰る、入る、走る、知る、切る 都是五段，需单独记
